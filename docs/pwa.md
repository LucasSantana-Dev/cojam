# PWA and the service worker

`apps/web/public/sw.js` exists for installability and one offline screen, not for speed. Navigations are network-first and fall back to the precached `/offline` page (plus the hashed `/_next/static` files that page needs, fetched on install). Nothing else is cached: not `/api/*`, not the websocket, not Centrifuge, not cross-origin YouTube or Spotify, not app chunks (the browser's HTTP cache handles those), and non-GET requests are ignored. The cache name is versioned (`cojam-offline-vN`), old caches are deleted on activate, and the worker uses `skipWaiting` plus `clients.claim`, so a deploy never leaves clients on a stale shell. `/sw.js` is served with `Cache-Control: no-cache, no-store, must-revalidate` (`next.config.ts`). It registers only when `NODE_ENV` is `production` (`ServiceWorkerRegister`). The production CSP needs no change: `worker-src` and `manifest-src` fall back to `default-src 'self'`. Regenerate icons with `node apps/web/scripts/gen-pwa-icons.mjs`.
